# Neosome API Parser hh.ru

#### Проект для поиска, фильтрации и сохранения вакансий с платформы hh.ru с использованием их публичного API.

### Описание
Данный проект позволяет:

- Выполнять поиск вакансий по заданному запросу.

- Фильтровать вакансии по ключевым словам в описании.

- Сохранять вакансии в локальный JSON-файл.

- Удалять вакансии из сохранённого файла.

- Выводить информацию о вакансиях в удобном формате.

### Структура проекта
-   ```src/```
    - ``` src/hh_api.py``` - класс для работы с API hh.ru.
    - ``` src/vacancies.py``` - класс для представления вакансий.
    - ```src/filters.py``` - функция фильтрации вакансий по ключевым словам.
    - ```src/file_reader_abc.py``` - абстрактный класс и реализация для работы с файлами JSON.

```main.py``` - основной скрипт для запуска программы.

-   ```tests/``` - тесты для основных модулей проекта.
    - ```test_hh_api.py``` - тесты для работы с API hh.ru.
    - ```test_vacancies.py``` - тесты для класса для представления вакансий.
    - ```test_filters.py``` - тесты для функции фильтрации вакансий по ключевым словам.
    - ```test_file_reader_abc.py``` - тесты для абстрактных классов и реализации для работы с файлами JSON.

```main.py``` - основной скрипт для запуска программы.
